My lean: Option A

  • Cleanest separation — these plots are storm-wide analysis, not per-frame products, so forcing them into the frame-viewer (B) fights the data shape
  • Grid view lets you show several related charts (e.g. all 3 quad-stats variants) together for comparison — natural for this content
  • Scales well if more summary/diagnostic plots get added later

Trade-off

  • A needs new nav entry + new page/section markup + grid CSS (more new code than B)
  • B/C reuse more existing plumbing but produce an awkward UX (animation controls for a non-animated product, or burying analysis charts in a dropdown)
